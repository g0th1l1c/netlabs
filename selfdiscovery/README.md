# selfdiscovery

Обнаружение копий себя в локальной сети через обмен multicast UDP-сообщениями.

Каждая копия периодически рассылает в multicast-группу сообщение «я жив» со
своим уникальным ID. По молчанию копии, от которых `timeout` нет вестей,
считаются пропавшими. При появлении/исчезновении/смене адреса копии список
живых копий печатается заново.

## Требования

- Go 1.22+
- Зависимость `golang.org/x/net` (подтянется автоматически)

## Сборка

```bash
go mod tidy        # один раз, чтобы скачать зависимости
go build -o selfdiscovery.exe .    # Windows
go build -o selfdiscovery .        # Linux/macOS
```

## Запуск

Адрес группы передаётся параметрами. Протокол (IPv4/IPv6) выбирается
автоматически по виду адреса группы, отдельного флага не требуется.

IPv4:

```bash
./selfdiscovery.exe -group 224.0.0.1 -port 9999
```

IPv6 (link-local группа, зона/интерфейс подставляется автоматически):

```bash
./selfdiscovery.exe -group ff02::1 -port 9999
```

Явный выбор интерфейса (если автоматический подбор выбрал не тот):

```bash
./selfdiscovery.exe -group 224.0.0.1 -port 9999 -iface "Ethernet"
```

### Флаги

| Флаг       | По умолчанию | Описание                                            |
|------------|--------------|-----------------------------------------------------|
| `-group`   | —            | IP multicast-группы (обязательный), без порта       |
| `-port`    | `9999`       | порт группы (1-65535)                               |
| `-iface`   | авто         | сетевой интерфейс                                   |
| `-interval`| `2s`         | период рассылки «я жив»                             |
| `-timeout` | `6s`         | таймаут до пометки копии пропавшей ( > interval)    |

## Проверка работоспособности

Два терминала на одной машине:

```bash
# терминал 1
./selfdiscovery.exe -group 224.0.0.1 -port 9999

# терминал 2
./selfdiscovery.exe -group 224.0.0.1 -port 9999
```

Каждая копия должна увидеть другую. Закрытие одной копии (Ctrl+C) приводит к
её исчезновению из списка другой примерно через `-timeout`.

## Формат сообщения

JSON, UTF-8:

```json
{"magic":"selfdiscovery-v1","id":"3fa2b91c77e04d15"}
```

- `magic` — метка протокола, отсекает посторонний multicast-трафик в группе;
- `id` — 16 hex-символов (8 случайных байт), уникален для каждого запуска.

## Реализация (кратко)

- приём и отправка через одну пару сокетов `net.ListenMulticastUDP` / `net.DialUDP`;
- сетевой интерфейс выбирается один раз и используется для приёма и отправки;
- для IPv6 link-локальных групп отправителю подставляется zone интерфейса;
- TTL (IPv4) / Hop Limit (IPv6) = 1 — рассылка не выходит из локального сегмента;
- собственные пакеты, вернувшиеся по multicast loopback, отсекает по `id`;
- учёт пиров ведётся по `id` (не по IP): несколько копий на одном хосте
  корректно считаются отдельными копиями;
- список печатается только при изменениях, отсортирован по IP.
