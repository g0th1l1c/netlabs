# selfdiscovery

Приложение обнаруживает копии самого себя в локальной сети через multicast
UDP-рассылку и печатает список идентификаторов "живых" копий при каждом
изменении (появлении/исчезновении).

## Сборка

```
go mod tidy   
go build -o selfdiscovery.exe ./cmd/selfdiscovery
или
go build -o selfdiscovery ./cmd/selfdiscovery
```

## Запуск

```
./selfdiscovery -group="[ff02::1]:9999" -iface="Беспроводная сеть" -interval=1s -timeout=3s         
./selfdiscovery -group="239.255.0.1:9999" -iface="Беспроводная сеть" -interval=1s -timeout=3s
```

Флаги:

| Флаг        | По умолчанию | Назначение                                             |
|-------------|---------------|---------------------------------------------------------|
| `-group`    | (обязателен)  | адрес multicast-группы, напр. `224.0.0.1:9999`          |
| `-iface`    | автоопределение | имя сетевого интерфейса                               |
| `-interval` | `2s`          | период рассылки "я жив"                                 |
| `-timeout`  | `6s`          | через сколько отсутствия считать копию пропавшей         |


## Обнаружение нескольких копий на одном компьютере

Каждая копия приложения при старте генерирует **уникальный
идентификатор**  из 8 случайных байт,
закодированных в hex (16 символов). Идентификатор не зависит от IP-адреса
и уникален для каждого процесса.

Обнаружение копий ведётся по этому ID: в таблице живых пиров ключом
служит `selfID`, а не IP-адрес. Поэтому несколько экземпляров
приложения, запущенных на **одном и том же компьютере** (и,
следовательно, с одним и тем же IP), учитываются **как разные копии**.

Когда копия завершается, она перестаёт рассылать сообщения "я жив".
Остальные копии через `-timeout` секунд удаляют её из своего списка
(через `RemoveExpired`), но **все прочие копии остаются в списке** —
удаляется только конкретный ID.


## Структура

```
go.mod
cmd/selfdiscovery/main.go          — флаги запуска, точка входа
internal/discovery/message.go      — формат сообщения "я жив"
internal/discovery/network.go      — разбор адреса группы, выбор IPv4/IPv6 и интерфейса
internal/discovery/multicast.go    — отправляющий сокет: интерфейс, TTL/HopLimit, loopback
internal/discovery/peers.go        — потокобезопасная таблица живых пиров
internal/discovery/discovery.go    — рассылка, приём, отслеживание таймаутов
```
